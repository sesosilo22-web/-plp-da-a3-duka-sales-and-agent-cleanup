# Duka Sales Analysis and Agent Transaction Cleanup

## Project Overview

This project focuses on analysing retail sales data and cleaning agent transaction records using Python and Pandas.

The project uses generated datasets to demonstrate data exploration, data cleaning, data validation, and reporting.

## Objectives

- Explore Duka retail sales data.
- Calculate revenue by branch and rank branches by performance.
- Analyse sales by product and sales channel.
- Identify premium online sales from the Coast and Capital regions.
- Clean agent transaction data by addressing duplicates, missing values, inconsistent transaction types, invalid dates, and unknown agents.
- Produce summary reports from cleaned transaction data.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Google Colab
- Microsoft Excel

## Project Tasks

### 1. Duka Sales Analysis

The sales analysis includes:
- Exploring the sales dataset.
- Calculating total revenue.
- Comparing branch performance.
- Analysing revenue by product and sales channel.
- Exporting premium online sales for the Coast and Capital regions.

### 2. Agent Transaction Cleanup

The cleaning pipeline addresses:
- Duplicate transaction records.
- Inconsistent transaction type formats.
- Missing and invalid transaction amounts.
- Date standardisation.
- Outlier identification.
- Unknown agent IDs.
- Merging agent information with transaction records.
